# Трекер целей с обратным отсчётом

Одностраничное браузерное приложение для постановки целей с дедлайном и живым таймером обратного отсчёта. Данные сохраняются в `localStorage`.

## Как открыть

**Вариант 1 — напрямую в браузере**

Откройте файл `index.html` двойным щелчком или перетащите его в окно браузера.

**Вариант 2 — локальный сервер (рекомендуется)**

```powershell
cd "C:\Users\10\Desktop\Мои цели"
npx --yes serve .
```

Затем откройте адрес из вывода команды (обычно http://localhost:3000).

## Открыть с телефона

1. **Дважды щёлкните** `start-for-phone.bat` в этой папке.
2. В открывшемся окне появится адрес вида **`http://192.168.x.x:3000`** — введите его в браузере на телефоне.
3. **Телефон и компьютер должны быть в одной Wi-Fi сети.** Окно на ПК не закрывайте, пока пользуетесь приложением с телефона.

**Если страница не открывается:** Windows может спросить разрешение для брандмауэра — нажмите «Разрешить доступ». Если окно не появилось, откройте «Брандмауэр Windows» → «Разрешить взаимодействие с приложением» и разрешите Node.js или Python для частных сетей.

**Данные на телефоне и на ПК хранятся отдельно** — у каждого устройства свой `localStorage`. Цели, добавленные на телефоне, не появятся на компьютере автоматически (и наоборот).

## Возможности

- Добавление цели: название + дата и время дедлайна
- Список целей с обратным отсчётом (дни / часы / минуты / секунды), обновление каждую секунду
- Отметить выполненной, вернуть в активные, удалить
- Сохранение в `localStorage` при обновлении страницы
- Состояния: до дедлайна, просрочено, выполнено
- Фильтры: активные / выполненные / все
- Интерфейс на русском языке

## Файлы

| Файл                 | Назначение                              |
|----------------------|-----------------------------------------|
| `index.html`         | Разметка страницы                       |
| `styles.css`         | Стили и адаптивность                    |
| `app.js`             | Логика и localStorage                   |
| `start-for-phone.bat`| Запуск для доступа с телефона (двойной щелчок) |
| `start-for-phone.ps1`| Скрипт сервера (вызывается из .bat)     |

Зависимости не требуются — только HTML, CSS и JavaScript. Для доступа с телефона нужен Node.js (`npx`) или Python.
